# v0.8.0 — La primera skill de `comun/`

> 12-08-2026 · commit `df21462` · 151 tests en verde

`comun/skills/` estaba vacía. Se relevó todo lo que había instalado en la máquina —23 skills
activas, dos propias y 21 de dos plugins de terceros— y de todo eso **una sola tenía que entrar
al harness**.

## Qué se hizo

- **`comun/skills/instalar-desde-github/`** — la disciplina para evaluar, instalar o tomar
  material de un repo de GitHub sin clonarlo: datos duros de la API, README crudo y filtrado,
  cinco preguntas respondidas **antes** de tocar la máquina, y el comando de desinstalación
  anotado junto al de instalación

No hizo falta tocar código: `install.ps1` ya copiaba `comun/skills/`.

## Qué se decidió, y por qué

**De `superpowers` (MIT, 14 skills) no se copia nada.** Son métodos genéricos sin una línea de
contenido GCBA, y copiarlos deja mantener método ajeno sin ganar nada específico. Cuatro
quedaron anotadas como referencia para cuando le tocara a `desarrollo`: TDD, debugging
sistemático, code review y cierre de rama.

**`ui-ux-pro-max` no entra, y conviene revisar si sigue prendido.** Su stack es shadcn/Radix/
Tailwind; el del GCBA es Obelisco, que es obligatorio por resolución. Y su `description` dispara
con *dashboard*, *admin panel*, *form*, *table* — o sea, con cada pantalla de un backoffice.

**La skill deja de afirmar el estado de una máquina.** Decía *"no hay `gh` en esta máquina"*,
cierto donde se escribió y falso en la de cualquier otro. Ahora se comprueba con `Get-Command`.
**El harness es para el equipo: una skill que afirma el estado de una máquina miente en todas
las demás.**

**Se le agregó el caso "no instalamos, tomamos".** Cuando la conclusión es *"de acá nos sirven
dos ideas"*, eso pasa a ser código de terceros dentro de un repo del GCBA: se lee entero, el
commit va exacto, la licencia se registra y se anota también lo que se dejó y por qué. Es el
procedimiento del ADR-0005, ahora accionable desde donde se decide.

## Lo que se rompió en el camino

Nada en el código. La cuarta trampa de la skill salió del caso real: **en Windows puede
directamente no haber binario.** `gentle-ai` retuvo su distribución para Windows por falta de
firma Authenticode — el README ofrece la instalación y en esa plataforma no existe.

## Lo que quedó abierto

- **La misma skill quedó en dos lugares** con el mismo nombre: la del harness y la personal en
  `~\.claude\skills\`. Al llamarse igual la del proyecto tapa a la personal, pero son dos
  archivos que se van a desincronizar
- **`superpowers` inyecta ~900 tokens en cada sesión** por su hook de `SessionStart`, y el
  presupuesto de siempre-cargado que se había fijado son 2.800. Un tercero se lleva cerca de un
  tercio y el `-Doctor` que iba a ser la compuerta mide solo lo propio
- El matcher de `SessionStart` del harness **no incluía `compact`** — se arregló en 0.9.0

## Dónde seguir

El relevamiento dejó dos cosas para cerrar, y las dos se hicieron en 0.9.0: el matcher de
`compact` y la medición de lo que queda fuera de las zonas.

Nota para retomar: **el presupuesto de contexto tiene que medir la sesión, no el harness.** Hoy
solo mide lo propio, y lo que se lleva un plugin de terceros es invisible.
