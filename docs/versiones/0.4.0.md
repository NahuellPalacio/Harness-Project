# v0.4.0 — La regla de secretos, punta a punta

> 10-08-2026 · commit `6392af8` · 104 tests en verde

_Reconstruida del `CHANGELOG` y del cuerpo del commit._

Es **lo único que el harness impide**. Todo lo demás avisa.

## Qué se hizo

- **`comun/hooks/lib/Secretos.psm1`** — detector con dos niveles de confianza
- **`comun/reglas/secretos.patrones.json`** — 12 patrones y 18 reglas de exclusión. Agregar un
  patrón o cambiar su severidad **no toca una línea de código**
- **`Write-HookAsk`** en `Hook.psm1` — la cuarta forma de salida, para el caso ambiguo
- El hook `PreToolUse` mira `content`, `new_string`, `command` y las ediciones de `MultiEdit`
- **`terceros/`** y **ADR-0005**

## Qué se decidió, y por qué

**Dos mecanismos complementarios, no alternativos.** `permissions.deny` protege lo que **no se
debe leer**; el hook de `PreToolUse` protege lo que **no se debe escribir**. El primero funciona
aunque los hooks estén rotos y cuesta cero, pero solo cubre lo que Claude Code resuelve como una
ruta.

**Dos niveles de confianza, y la distinción importa más que los patrones: alta bloquea, media
pregunta.** Lo ambiguo lo decide la persona, no el harness. **El falso positivo es el riesgo
existencial**: un harness que traba trabajo legítimo se desinstala esa semana, y ahí se pierde
también la protección real.

**16 de los tests nuevos son casos que NO deben bloquear.** Valen tanto como los positivos.

**El motivo del bloqueo nunca repite el secreto.** Entra al contexto y queda en la transcripción,
así que informa **forma y largo**, no el valor.

**Lo bajado de repos públicos vive aparte, con procedencia registrada, y no es fuente de
instalación** (ADR-0005). Una skill ajena es texto que el modelo obedece, no una librería que se
llama.

## Lo que se rompió en el camino

**La exclusión de placeholders recibía la coincidencia entera en vez del valor**, así que ningún
patrón anclado podía matchear: una asignación de contraseña con un relleno obvio se bloqueaba
como si fuera una credencial real. Se separó la extracción del valor de la coincidencia, con
`Get-ValorDeAsignacion`.

## Lo que quedó abierto

- **Límite honesto que quedó escrito en el README**: `permissions.deny` solo cubre lo que se
  resuelve como ruta. Una lectura indirecta —construir el path en una variable— puede escapar.
  Es *best-effort*, no una garantía

## Dónde seguir

Lo siguiente era el `CLAUDE.md` canónico y la capa de memoria (0.6.0).

Para agregar un patrón nuevo no hace falta tocar código: se edita
`comun/reglas/secretos.patrones.json` y se le pone severidad `alta` (bloquea) o `media`
(pregunta). Conviene sumar el caso negativo al test en el mismo movimiento.

⚠️ **Escribir documentación sobre el detector puede disparar el detector.** Pasó al redactar
esta misma nota: un ejemplo de asignación con relleno, entre comillas invertidas de markdown,
bloqueó la escritura. Ver `docs/versiones/0.12.0.md` — de ahí salió el arreglo.
